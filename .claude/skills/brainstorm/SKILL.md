# Brainstorm Review

Review ideas captured from Telegram brainstorming sessions.

## Commands

- `/brainstorm list` - Show all saved ideas
- `/brainstorm review <name>` - Review and refine a specific idea
- `/brainstorm prd <name>` - Convert idea to PRD for Ralph execution

## Workflow

1. List recent ideas: `ls docs/ideas/`
2. Read an idea: Read the file
3. If ready, run `/prd docs/ideas/{name}.md` to convert to executable PRD
